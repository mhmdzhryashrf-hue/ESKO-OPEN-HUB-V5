|---|---|---|
| الهوية والشريط العلوي والبحث | منفذ محلياً | بحث في المنشورات المحلية؛ ليس بحثاً عاماً على الخادم |
| التبويبات الستة | منفذ محلياً | مطابق لترتيب الوثيقة العربية |

| المحادثات والمجموعات | مساحات محلية | لا اتصال حي، لا حضور، لا اتصال صوتي/مرئي |
| المستودعات والملفات | منفذ محلياً | IndexedDB، حد 50MB لكل ملف، غير مشفر على خادم |
| خلفية المستودعات | منفذ محلياً | صورة المستخدم بعتامة 10.5% وطبقة تعتيم |
| المتجر والمنتجات والسلة | تجربة محلية | لا شراء ولا دفع ولا شحن أو تسويات |
| المساعد الذكي | مساعد قواعد محلي | لا نموذج توليدي أو مصادر ويب أو أدوات خارجية |
| 25 وحدة التحديث الثاني | الكتالوج منقول | وصف وبيانات وعدادات؛ ليست وحدات إنتاجية منفصلة |

| 2,000 نسخة خادم منطقية | كتالوج | 200 عائلة × 10 نسخ منطقية |
| 4,000 وحدة معالجة برمجية | كتالوج | 400 عائلة × 10 وحدات |
| 1,000 أمر تحديث ثانٍ | كتالوج قوالب | 25 وحدة × 40 أمراً |
| 200 سيناريو تحديث ثانٍ | كتالوج قوالب | 25 وحدة × 8 سيناريوهات |
| Android | مصدر WebView | غير مبني إلى APK في هذه البيئة |
| الحسابات والتحقق الحقيقي | غير متصل | يحتاج API ومزود بريد/OTP وقاعدة بيانات |
| دردشة بين مستخدمين | غير متصل | يحتاج WebSocket/خدمة مراسلة وتخزيناً خادمياً |
| رفع ملفات سحابي وفحص malware | غير متصل | الملفات تبقى في IndexedDB على الجهاز |
| معالجة الفيديو والبث المباشر | غير متصل | يحتاج ترميزاً وتخزيناً وCDN وبنية بث |
| مدفوعات المتجر | غير متصل | يحتاج مزود دفع مرخصاً وسياسات استرداد |
| الذكاء الاصطناعي المتصل | غير متصل | يحتاج موفر AI وخادماً يحفظ الأسرار |
| خرائط/موقع/إشعارات Push | غير متصل | يحتاج موافقات وربط مزودين |

## ضوابط المصدر

1. لا ينفذ المساعد أوامر نشر أو حذف أو شراء أو إرسال نهائي دون تأكيد.
2. لا تُعرض الرسائل المحلية في البحث العام.
3. لا يُعامل البلاغ وحده كدليل على المخالفة.
4. لا تنفذ عائلات الأوامر غير المرتبطة بعقد API موثق.
5. لا تعتبر أعداد الخدمات أو المعالجات المنطقية أجهزة مادية.

## فروق وجوانب تحتاج قراراً أو استكمالاً

- الوثيقة الرئيسية تنص على ستة تبويبات سفلية؛ لذلك المساعد في الشريط العلوي، وليس تبويباً سابعاً.
- نص السيناريوهات يذكر 50 قالباً × 60 تنويعاً، بينما جدول المعرفات يعرض 60 قالباً × 50 تنويعاً. تم اتباع معرفات الجدول المرقمة وإظهار الملاحظة.
- جدول عائلات الأوامر لم يوفر 24 اسماً عائلياً، وجدول الخدمات 29، وجدول المعالجات 29. سجلات الاستكمال موسومة `generated-gap-record` وليست منسوبة للمصدر.
- الأرقام 700,000 و4,000 و2,000 تمثل معرفات/نسخاً/وحدات منطقية بحسب الوثائق، وليست وظائف مكتملة أو أجهزة فعلية.
