# مِحور MIHWAR — حزمة تنفيذ المواصفات v1.1

هذه حزمة مشروع قابلة للتشغيل محلياً ومبنية على المستندات الخمسة المرفوعة. واجهة الويب تعمل كتطبيق محلي/PWA، وتحفظ بيانات التجربة في المتصفح وعلى الجهاز. ليست هذه الحزمة منصة متعددة المستخدمين متصلة بخادم إنتاجي.

## ما تم تنفيذه داخل الحزمة

- شريط علوي فيه البحث الموحد وزر المساعد ومراكز مِحور.
- ستة تبويبات سفلية كما في الوثيقة العربية: البيت، الإعدادات، المناقشات، المستودعات، المتجر، الحساب. المساعد عنصر علوي دائم وليس تبويباً سابعاً.
- البيت: إنشاء منشور بعد معاينة وتأكيد، موجز محلي، إعجاب، تعليق، حفظ، نسخ، إخفاء، وإبلاغ محلي.
- الحساب: تحرير الاسم والنبذة، تفضيل الخصوصية محلياً، مسودات واستعادة المسودات إلى معاينة النشر، وسجل نشاط محلي.
- المناقشات: إنشاء مساحات ومراسلات محلية على الجهاز. لا يوجد إرسال حي إلى مستخدمين آخرين.
- المستودعات: إضافة ملفات إلى IndexedDB، إنشاء مجلدات، بحث وتنزيل وحذف الملفات. صورة الدرع المرفقة مستخدمة كخلفية منخفضة الشفافية مع طبقة تعتيم عالية للحفاظ على الوضوح.
- المتجر: إضافة منتجات محلية، بحث، سلة، وحفظ طلب معاينة غير مدفوع. لا توجد بوابة دفع أو معاملات مالية.
- الإعدادات: مظهر فاتح/داكن، تقليل الحركة، تفضيلات محلية، العربية افتراضياً، تصدير البيانات ومسحها.
- المساعد: بحث وتلخيص وصياغة مسودات محلياً وفق قواعد بسيطة. ليس متصلاً بنموذج توليدي أو موفر خارجي.
- مراكز مِحور: كتالوج الوحدات الـ25 الواردة في تحديث المواصفات الثاني.
- مستكشف الأوامر: بحث في معرفات العائلات والسيناريوهات والخدمات والوحدات، مع توضيح ما إذا كان المعرف مفهرساً فقط أو وصفاً منطقياً.
- مراكز MIHWAR STUDIO / AI / CLOUD / MARKET / WORLD / ADMIN، مع إنشاء مسودات مواصفات في Studio للمعاينة فقط.
- نسخة PWA مع Service Worker للملفات الأساسية بعد أول تحميل.
- مصدر Android WebView مستقل لعرض تطبيق الويب محلياً.

معرفات 700 ألف أمر لا تُخزن كسطور ضخمة؛ يتم توليدها عند الطلب من 700 عائلة × 1,000 تنويع، وفق طريقة الوثيقة. **المعرف في الكتالوج ليس دليلاً على وجود endpoint أو تنفيذ إنتاجي.**

## ملاحظات تدقيق على المصدر

- صفحة كتالوج الأوامر الأساسية تعلن 700 عائلة؛ استخراج صفوف الجداول أعطى 676 تعريفاً واضحاً. تمت إضافة 24 سجلاً بعلامة `generated-gap-record` لاستكمال النطاق الحسابي، مع التصريح بأنها غير موثقة في جدول المصدر.
- كتالوج الخوادم يعلن 200 مجموعة × 10 نسخ. تم استخراج 171 مجموعة، واستكملت 29 مجموعة بسجلات فجوة واضحة؛ النسخ وحدات منطقية وليست أجهزة فعلية.
- كتالوج المعالجات يعلن 400 عائلة × 10 وحدات. تم استخراج 371 عائلة، واستكملت 29 بعلامة فجوة واضحة؛ هذه وحدات برمجية وليست CPU/GPU.
- جدول السيناريوهات يعرض 60 قالباً ولكل قالب 50 معرفاً (المجموع 3,000)، بينما نص الفقرة يذكر 50 قالباً × 60 حالة. تم اتباع نطاقات المعرفات الظاهرة في الجدول: 60 × 50.
- تحديث المواصفات الثاني يعرّف 25 وحدة، 40 أمراً و8 سيناريوهات و4 خدمات و6 معالجات لكل وحدة. قوالب الأوامر عامة وتحتاج تخصيصاً وربط صلاحيات واختبارات.

## التشغيل على الكمبيوتر

يتطلب Python 3 فقط لتشغيل خادم الملفات المحلي:

```bash
cd web
python -m http.server 8080
```

افتح `http://127.0.0.1:8080` في المتصفح. لا تفتح `index.html` مباشرة عبر `file://` لأن المتصفح يمنع تحميل كتالوج JSON في بعض الإعدادات. لإيقاف الخادم اضغط `CTRL+C`.

## التشغيل على Termux

```bash
pkg update -y
pkg install -y python unzip git
unzip MIHWAR-V1.1-Implementation.zip
cd MIHWAR-V1.1-Implementation
bash scripts/verify.sh
bash scripts/termux-start.sh
```

ثم افتح `http://127.0.0.1:8080` من متصفح الهاتف. لإيقاف الخادم اضغط `CTRL+C`.

## تطبيق Android

يوجد مشروع مصدر Android WebView في `android/`. لم يتم تسليم APK مبني لأن بيئة البناء الحالية لا تحتوي Android SDK أو Gradle. افتح مجلد `android` في Android Studio وابنِ `assembleDebug` بعد تنزيل مكونات Android الرسمية.

## ما يحتاج خادماً وخدمات خارجية قبل إطلاق عام

تسجيل حساب موثق، بريد/OTP، MFA، جلسات متعددة الأجهزة، PostgreSQL، Redis، بحث وفهرسة، دردشة آنية بين حسابين، تخزين ملفات سحابي وفحص malware، معالجة صور وفيديو، بث مباشر، خرائط وموقع، بوابة دفع معتمدة، تسويات البائعين، إشعارات Push، إدارة بلاغات ومراجعة بشرية، موفر ذكاء اصطناعي، ومراقبة وتشغيل ونسخ احتياطية. لا توجد أسرار أو مفاتيح خدمات مضمنة.

## الاختبارات المنفذة
