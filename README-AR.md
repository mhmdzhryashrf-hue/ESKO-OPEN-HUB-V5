# ESKO OPEN HUB V5.0

حزمة مصدر موحّدة لواجهة الموقع، وخادم الحسابات والمناقشات، وطبقة الألعاب والأدوات والبوتات، ومصدر Android WebView.

## ما تم دمجه

- واجهة RTL موحّدة من خط V4.5 مع طبقة V5 ومكونات UI السابقة المتوافقة.
- خلفية بحرية متحركة بحركة CSS خفيفة، مع شكل ظلي أصلي لشخصية مقنّعة تنظر إلى الأفق. لا يستخدم التصميم نسخة من شخصية فيلم محمية.
- مقدمة مدتها 6 ثوانٍ، وشعار نسر هندسي يظهر تدريجيًا بخطوط متتابعة.
- 1000 بطاقة كتالوج موزعة على عشرة أقسام، مع بحث داخلي.
- 50 قالب بوت، و50 لعبة في الكتالوج؛ عشرة محركات ألعاب محلية قابلة للعب والباقي موسوم بوضوح بأنه غير مفعّل.
- قسم الحساب، والمحادثة العامة والمجموعات والرسائل الخاصة بعد قبول الطلب، والحظر والإبلاغ.
- انتهاء تلقائي لرسائل المناقشات بعد 7 ساعات، وتنظيف دوري وتنظيف عند بدء الخادم.
- جلسات خادمية مستمرة بعد إعادة تشغيل الخادم، محفوظة كـ SHA-256 hashes لا كرموز جلسات خام، وتُبطل عند استعادة الحساب.
- ضغط الصور الشخصية إلى WebP لا يتجاوز 300KiB، والتحقق من صورة الخلفية قبل تحميلها.
- حد اتصال أدنى مقداره 2KiB/s في نسخة الموقع المنشورة.
- زر دعم ثابت، وقسم إخلاء مسؤولية، وإعدادات للخلفيات والأصوات، ودعم تقليل الحركة.

## مهم: ما هي الأشياء الموجودة فعلًا؟

**الـ1000** هي بطاقات كتالوج موزعة على 10 أقسام، وليست 1000 أداة مستقلة منفذة. بطاقات التعريف لا تدّعي تشغيل وظيفة لم تُبرمج بعد.

**البوتات الـ50** قوالب جاهزة للتخصيص؛ تشغيل كل بوت على Telegram أو Discord أو منصة أخرى يحتاج Adapter رسميًا ومفاتيح خدمة خاصة تُخزّن في الخادم، وليس في ملفات الواجهة.

**الألعاب الـ50** تضم 10 ألعاب لها محركات محلية داخل التطبيق، بينما بقية العناصر في الكتالوج لا تظهر كأنها تعمل.

**المحادثات** تحفظ على الخادم وتُحدّث عبر polling كل 5 ثوانٍ في الواجهة الأساسية، وليست WebSocket push حقيقيًا. تُحذف رسائلها بعد 7 ساعات. قد تظل نسخ لدى المستلمين أو ضمن نسخ احتياطية يضبطها مشغل الاستضافة.

**التخزين** في هذا الإصدار ملف JSON دائم ومناسب لتشغيل نسخة واحدة (single instance) مع قرص دائم. لا تشغّل عدة نسخ من الخادم على نفس ملف البيانات. للتوسع متعدد الخوادم يجب نقل قاعدة البيانات إلى PostgreSQL وإضافة بث WebSocket مُدار.

**المعالج** المقصود هو منسق أداء برمجي: يوقف Canvas عند إخفاء الصفحة أو تفعيل تقليل الحركة، ويحد كثافة الرسم ويستخدم تحميل الصور المضغوطة. لا يمكن لبرنامج أن يضيف أنوية CPU أو يرفع سرعة الشبكة الفعلية.

## تشغيل الموقع محليًا

المتطلبات: Node.js 20 أو أحدث.

```bash
npm run check
npm test
npm start
```

يفتح الموقع على `http://127.0.0.1:8788` افتراضيًا. يخزن الخادم بياناته في `backend/data/database.json` مع أذونات ملفات مقيدة. في النشر، عيّن `ESKO_DATA_DIR=/data` واربط Volume دائمًا على `/data`.

## نشر الموقع

يوجد `Dockerfile` و`railway.toml` جاهزان كبداية نشر على Railway أو أي استضافة تدعم Docker.

1. أنشئ مستودع Git باسم `ESKO-OPEN-HUB-V5.0` وارفع محتويات هذا المجلد إلى الفرع الأساسي.
2. أنشئ مشروعًا من المستودع في خدمة الاستضافة.
3. أضف Volume دائمًا إلى المسار `/data`.
4. عيّن `NODE_ENV=production` و`ESKO_HOST=0.0.0.0` و`ESKO_DATA_DIR=/data`. المنصة تضبط `PORT` تلقائيًا.
5. أبقِ عدد نسخ الخادم على نسخة واحدة لهذا التخزين الحالي.
6. اختبر `/api/health`، ثم أنشئ حسابين تجريبيين واختبر الحسابات والمناقشة والإبلاغ وانتهاء الرسائل.

لا توجد قاعدة بيانات أو خدمة مستضافة تم إنشاؤها بواسطة هذه الحزمة؛ يجب إنشاء مشروع الاستضافة والـVolume وربط النطاق من حساب مالك المشروع.

## ربط تطبيق Android بالموقع نفسه

داخل مجلد `android` يوجد مشروع Android Gradle. افتحه في Android Studio، وضع رابط النشر في `android/gradle.properties` كسطر `ESKO_SITE_URL=https://YOUR-DOMAIN.example`، ثم نفّذ Build APK من القائمة. ويمكن البناء من الطرفية عند تثبيت Gradle باستخدام الخاصية:

```bash
cd android
gradle assembleDebug -PESKO_SITE_URL=https://YOUR-DOMAIN.example
```

يُحمّل التطبيق عندها نفس واجهة الموقع وAPI من نفس النطاق، فيستخدمان حسابات وبيانات ومحادثات الخادم نفسها. سيظل تسجيل الدخول مستقلًا لكل حاوية متصفح؛ يسجل المستخدم الدخول مرة داخل الموقع ومرة داخل التطبيق، لكن قاعدة الحسابات والرسائل مشتركة.

عند ترك `ESKO_SITE_URL` فارغًا، يفتح التطبيق ملفات محلية للمعاينة فقط؛ الحسابات والمحادثات الشبكية لن تعمل لأن الخادم ليس مضمّنًا داخل APK. لم يُنتج APK في بيئة البناء هذه لعدم توفر Android SDK/Gradle executable.

## الأسرار والحماية

- لا تضع كلمة مرور GitHub أو الاستضافة أو مفاتيح البوت في المحادثة أو داخل `public/`.
- خزّن أسرار تكاملات البوت على الخادم كمتغيرات بيئة.
- استخدم HTTPS، وقرصًا دائمًا للبيانات، ونسخًا احتياطية محمية.
- حدّث قائمة الحظر والإبلاغ وسياسة الإشراف قبل فتح التسجيل العام.
- لا تسمح بفحص نطاق إلا بملكية أو تصريح؛ الفاحص الحالي محدود بترويسات HTTPS فقط.

## روابط الأقسام

- `/` واجهة ESKO V5.0
- `/api/health` فحص الصحة والإصدار ومدة الاحتفاظ بالرسائل
- `/v5/tools.json` كتالوج الأدوات والأقسام العشرة
- `/v5/games.json` كتالوج الألعاب
- `/v5/bots.json` قوالب البوتات
