# نتائج الفحوص المحلية

يُعاد تشغيل `bash scripts/verify.sh` من جذر الحزمة.

| الفحص | النتيجة |
|---|---|
| صياغة JavaScript (`node --check`) | ناجح |
| قراءة JSON للكتالوج | ناجح |
| عدد عائلات الأوامر الأساسية | 700 بعد إظهار 24 سجل فجوة معلناً |
| معرفات الأوامر الأساسية الحسابية | 700,000 مولدة عند الطلب |
| قوالب السيناريوهات الأساسية | 60 قالباً / 3,000 معرف |
| مجموعات الخوادم المنطقية | 200 × 10 = 2,000 |
| عائلات وحدات المعالجة | 400 × 10 = 4,000 |
| وحدات تحديث المواصفات | 25 |
| أوامر تحديث المواصفات | 1,000 |
| سيناريوهات التحديث | 200 |
| الخدمات المنطقية للتحديث | 100 |
| معالجات التحديث | 150 |
| HTML وملفات الموارد | موجودة |
| اختبار روابط الموارد والكتب ومصفوفة التنفيذ عبر خادم محلي | 10 مسارات أعادت HTTP 200 |
| بناء APK باستخدام Android Gradle Plugin | لم يُنفذ: Android SDK وGradle غير متاحين في بيئة البناء |
| تشغيل خادم الملفات وطلب الصفحة عبر HTTP | ناجح: الصفحة والكتالوج والموارد الأساسية ترجع HTTP 200 |
| تشغيل واجهة Chromium headless | غير مكتمل: تعذر تشغيل عملية المتصفح في بيئة البناء؛ لا يُسجل كاختبار نجاح |

لا تعني النتائج أعلاه تشغيل خوادم إنتاجية أو اختبار حسابات متعددة أو اختبار دفع أو بث أو اختباراً أمنياً مستقلاً. تشغيل المتصفح الرسومي لم يكتمل، لذلك يلزم اختبار يدوي على Chrome/Android بعد فك الحزمة. اختبار HTTP يتحقق من إتاحة الملفات، ولا يثبت صحة التفاعلات داخل WebView. اختبارات الوظائف المتصلة لا يمكن اجتيازها قبل ربط الخدمات المعنية.
